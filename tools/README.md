# 제한속도 데이터 준비 도구

공공데이터를 앱이 쓸 수 있는 형태로 변환하는 스크립트입니다.
파이썬 표준 라이브러리만 씁니다. 외부 패키지 설치가 필요 없습니다.

원본 데이터와 생성된 DB는 재배포 조건 확인 전까지 저장소에 넣지 않습니다.
각자 내려받아 생성하세요.

## 필요한 원본 데이터

| 데이터 | 받는 곳 | 비고 |
|---|---|---|
| 표준노드링크 | [ITS 국가교통정보센터](https://www.its.go.kr/nodelink/nodelinkRef) | 최신 `NODELINKDATA.zip` 1개. API 키 불필요 |
| 전국어린이보호구역표준데이터 | [공공데이터포털](https://www.data.go.kr/data/15012891/standard.do) | CSV |

`NODELINKDATA.zip` 안의 `MOCT_LINK.*` 를 `tools/nodelink/` 에 풀어 둡니다.

## 사용법

```bash
cd tools
python build_speedlimit_db.py --region daejeon --out speedlimit_daejeon.db
```

`--region` 은 `build_speedlimit_db.py` 의 `REGIONS` 에 정의돼 있습니다.
노선이 시·도 경계를 넘으면 그 표에 범위를 넓혀 추가하세요.

## 파일

| 파일 | 역할 |
|---|---|
| `tm.py` | EPSG:5186(중부원점, GRS80) ↔ WGS84 변환. 표준노드링크의 좌표계입니다 |
| `build_speedlimit_db.py` | 지역 링크 추출 → 앱용 SQLite 생성 |
| `check_schoolzone.py` | 노드링크 `MAX_SPD`가 어린이보호구역을 얼마나 반영하는지 실측 |

## 어린이보호구역을 제한속도로 덮어쓰지 않는 이유

`check_schoolzone.py` 로 대전 영역(링크 35,447개, 보호구역 749곳)을 확인한 결과입니다.

| 보호구역에서의 거리 | 링크 수 | `MAX_SPD`=30 | 40 이상 |
|---|---|---|---|
| 30m 이내 | 315 | 82.5% | 14.9% |
| 50m 이내 | 896 | 79.7% | 18.3% |
| 100m 이내 | 3,127 | 71.7% | 27.0% |
| 300m 이내 | 15,122 | 50.9% | 47.8% |
| 대전 전체 | 35,447 | 35.3% | — |

학교 인접 도로는 노드링크가 이미 82.5%를 30km/h로 표시하고 있습니다.

반면 어린이보호구역 표준데이터에는 **제한속도 컬럼이 없고 구역 경계도 없습니다.**
있는 것은 학교 건물의 좌표 한 점뿐입니다. 이 점에 반경을 씌워 30으로 덮어쓰면,
300m 반경 기준 47.8%의 링크가 실제로는 40 이상인데 30으로 바뀝니다.
학교 옆을 지나는 간선도로가 전부 30이 되어 과속 오탐이 커집니다.

그래서 이렇게 나눴습니다.

- **제한속도의 출처는 표준노드링크 `MAX_SPD` 하나뿐입니다.**
- 어린이보호구역은 **주의 플래그**로만 씁니다. 학교 50m 이내인데 `MAX_SPD`가
  40 이상인 링크(`links.school_suspect = 1`)에서는 앱이 과속 판정을 보류합니다.
  대전 기준 197개로 전체의 0.4% 수준이라 잃는 것이 거의 없습니다.

확실하지 않으면 경고하지 않는다는 이 앱의 원칙과 같은 처리입니다.

## 생성되는 DB 구조

대전 기준 링크 49,837개, 세그먼트 324,249개, 약 10MB입니다.

```sql
meta(key, value)              -- 지역, 범위, 격자 크기, 출처, 생성 기준값
links(
  id, link_id, max_spd, road_rank, road_name,
  school_suspect,             -- 1이면 과속 판정 보류
  geom                        -- float32 (lat, lon) 쌍의 나열
)
seg_index(cx, cy, link, seg, bearing)   -- 200m 격자. WITHOUT ROWID
```

앱은 GPS 좌표가 속한 격자와 주변 8칸에서 후보 세그먼트를 뽑고,
`bearing` 을 GPS 진행방위와 비교해 반대 차선과 교차 도로를 걸러냅니다.
